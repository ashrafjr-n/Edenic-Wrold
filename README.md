# Edenic World

An educational web app for kids aged 5–9. Three mascots — Pinki, Nova and Bloo — teach short video-led courses, and a Play section adds puzzles, a memory game and Nova's cups game. A course's lessons can happen in a pre-rendered 3D world of their own (Pinki's shape garden and colour forest so far): each activity is a camera shot of it, the moves between them are rendered camera moves, and the lesson ends there with the friend celebrating; a course without a world ends back on the friend's chalkboard with the path it walked. The interface reads in English, Arabic and Badini Kurdish.

## Tech Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Zustand · Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).
