# Edenic World

An educational web app for kids aged 5–9. Three mascots — Pinki, Nova and Bloo — teach short video-led courses (real clips, compressed to 720p H.264 by `tools/reels/encode.sh`), and Play is the Sleeping Lab: the Edenic Laboratory of episode 2, pre-rendered in 3D at the end of a candy cobble path, where five cookie stages (being built one at a time) wake the lab part by part until its door opens; three free games — jigsaw puzzles, Memory Match and Nova's cups — sit behind its Games button. Play is still being built, so the Discover page shows it as coming soon; Watch leads with the series' YouTube episodes, which take turns in one hero, and then the lessons' short videos. Every course's lessons happen in a pre-rendered 3D world of their own (Pinki's felt-land shape garden and pastel colour land, Nova's kitchen and her candy-pink garden, Bloo's sunny farm for Animals and his floating island of the year for Seasons and Weather) — each season's lessons turn the whole island into that season, and after the weather's reel it rains, shines, blows or snows there. Every course page is itself a 3D world of stops where scrolling moves the camera: each activity is a camera shot of it, the moves between them are rendered camera moves, and the lesson ends there with the friend celebrating. Finishing a course opens its gold chest, which gives the course's star; each friend's pages carry a star pod under the back button (a white clay chip, "1/2", that opens into one slot per course — a pale clay star or the gold one), which opens by itself when a new star arrives. The world's frames are cached by the browser for good (their URLs carry a content hash), so a second visit loads them instantly. The first visit of a session opens on a short clay splash (the logo's two words bounce in and its star spins on, plain CSS, about a second and a half), and photos blur in from a tiny preview while they load. Learn has sound: every taught word is spoken (American English, made with the Kokoro text-to-speech model), and every button, letter, find, feeding, finished lesson, opened chest and cloud transition has its own soft toy-like sound, synthesised from scratch — both are generated by `tools/sounds/` and played with the Web Audio API. The interface reads in English, Arabic and Badini Kurdish.

## Tech Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS v4 · Zustand · Lucide icons · Web Audio

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000).

## Sounds

The clips live in `public/assets/audio/` and are made, not downloaded:

```bash
python3 tools/sounds/sfx.py [id …]               # sound effects → audio/sfx/ (needs numpy, ffmpeg)
venv/bin/python tools/sounds/words.py <models>   # spoken words → audio/words/ (kokoro-onnx; see the script)
```

After remaking a clip, bump `V` in `src/lib/cue.ts` so browsers fetch it again.
